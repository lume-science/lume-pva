# Gaussian Signal Processing Examples

## Overview

A beam profile signal processing pipeline demonstrating lume-pva with independent processes:

```
gaussian_sim.py ──PVA──► gaussian_classical.py (scipy curve_fit)
                ──PVA──► gaussian_ml.py (PyTorch neural network)
```

A noisy Gaussian simulator publishes data. Two independent denoisers subscribe, estimate beam parameters, and publish results — one using classical curve fitting, the other using a trained neural network.

## Prerequisites

```bash
conda activate lume-pva
pip install -e ".[dev]"        # core + testing
pip install -e ".[dev,torch]"  # add PyTorch support for ML example
```

## Quick Start

```bash
# Terminal 1: Start simulator
python examples/gaussian_sim.py

# Terminal 2: Start classical denoiser
python examples/gaussian_classical.py

# Terminal 3: Train and start ML denoiser
python examples/gaussian_train.py   # one-time, generates gaussian_model.pt
python examples/gaussian_ml.py

# Terminal 4: Compare results against ground truth
pvmonitor SIM:mean est_mean ml_est_mean SIM:sigma est_sigma ml_est_sigma
```

## Files

| File | Purpose |
|------|---------|
| `gaussian_sim.py` | Publishes noisy Gaussian beam profiles (p4p direct, no Runner) |
| `gaussian_classical.py` | Subscribes to simulator, estimates params via scipy curve_fit |
| `gaussian_train.py` | Generates training data, trains MLP, saves `gaussian_model.pt` |
| `gaussian_ml.py` | Subscribes to simulator, estimates params via trained neural network |

## Architecture

- **Simulator** uses `p4p` directly (no Runner, no CA, PVA only)
- **Denoisers** use the standard `LUMEModel` + `Runner` pattern
- All processes are independent — start/stop/restart without affecting each other
- Both denoisers subscribe to the same simulator PVs simultaneously

## PVs

**Simulator (PVA only):**
- `SIM:noisy_signal` — 256-point noisy Gaussian array
- `SIM:x_axis` — x coordinates (-10 to +10 mm)
- `SIM:mean`, `SIM:sigma`, `SIM:snr` — ground truth scalars

**Classical denoiser (CA + PVA):**
- `est_mean`, `est_sigma`, `est_amplitude` — estimated parameters
- `denoised_signal` — reconstructed clean signal
- `fit_quality` — R² goodness of fit

**ML denoiser (CA + PVA):**
- `ml_est_mean`, `ml_est_sigma`, `ml_est_amplitude` — estimated parameters
- `ml_denoised` — reconstructed clean signal
- `ml_fit_quality` — R² goodness of fit
- `ml_infer_time` — forward pass duration (seconds)

## EPICS Environment (Local Development)

```bash
export EPICS_CA_ADDR_LIST=127.0.0.1
export EPICS_CA_AUTO_ADDR_LIST=NO
export EPICS_PVA_ADDR_LIST=127.0.0.1
export EPICS_PVA_AUTO_ADDR_LIST=NO
```

## Notes

- Start the simulator before the denoisers (they subscribe to its PVs)
- `gaussian_model.pt` is generated by `gaussian_train.py` and is not checked into git
- The ML denoiser runs on CPU by default (~0.4 ms per inference)
- Both denoisers run without prefixes; use unique prefixes in production to avoid PV name collisions
